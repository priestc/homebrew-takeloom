# homebrew-takeloom

Homebrew tap for [takeloom](https://github.com/priestc/takeloom), a music
recording session manager.

```bash
brew install priestc/takeloom/takeloom
takeloom install-launcher   # optional: add it to Applications / your app menu
```

That's the latest release. `brew upgrade` picks up new ones. To build
GitHub's `main` instead: `brew install --HEAD priestc/takeloom/takeloom`.

The formula is updated automatically by takeloom's release workflow, so
don't edit its `url`/`sha256` by hand.
